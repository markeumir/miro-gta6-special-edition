# MiRo GTA 6 Special Edition v1.4

**PWA & SCOOP Weapons Cache Edition** — an unofficial, independent gaming companion by MiRo Digital Tools. Not affiliated with Rockstar Games. Gameplay claims and payouts are reported research, not guarantees.

## Hosting on GitHub Pages

Upload the contents of this folder (not the enclosing directory) to the root of `markeumir/miro-gta6-special-edition` on `main`. Enable Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save. Intended site: https://markeumir.github.io/miro-gta6-special-edition/ (not verified live). Do not upload the developer edition, backup files or recovery packages to this public repository.

## Install and use

Open the HTTPS site in a supported browser. Use Install app or the browser's install/add-to-home-screen menu. On iPhone/iPad use Safari's Share → Add to Home Screen. Allow the initial online load and offline setup to finish before disconnecting. External guides, images and maps need internet. The app does not import PS5 saves.

## Preserve progress

Export JSON from your old standalone guide (Notes & backup) and import it into the PWA. Browser local storage is origin-specific and not synced across devices. The app retains the original storage key and backup format. Export periodically.

## Release scope

Includes all prior modules and the new reported Draper Bay weapons cache. Chapter 3 unlock and Port Gellhorn cache are guide-backed; exact map match and item inventory are not confirmed. No new cash reward or weapon identities are asserted.

Static checks and simulated service-worker tests passed; actual browser installation, offline reload, responsive interaction and live deployment still require testing. The protected data encoding is reversible, not a security boundary. No developer source or user backups should be published.
